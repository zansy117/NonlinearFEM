# NonlinearFEM 程序手册

版本：源码工作版初稿；编写日期：2026-11-20。适用对象是当前仓库中的程序，不是此前发布的 v0.1.0 软件包。

本套手册按“原理与算法、用户操作、算例验证”分工编写。算例报告记录源码和可执行文件指纹；修改程序后应重新运行，不能沿用旧报告宣称新版本已经验证。

| 手册 | 读者与内容 |
| --- | --- |
| [理论手册](THEORY.md) | 理解有限变形运动学、材料关系、离散、静力迭代和显式时间积分，以及实际实现的边界 |
| [用户手册](USER.md) | 从编译、启动、建模到计算、云图、导出和问题排查的完整流程 |
| [算例手册](EXAMPLES.md) | 六个冻结的解析输入算例、四组复用既有验证程序的算例，以及通过标准和复现方法 |
| [基准实测报告](verification/2026-11-20/REPORT.md) | 本轮实际结果；同目录有 JSON 指纹、输入快照、CSV 和完整日志 |

输入文件位于 [examples/standard](../examples/standard/)。复现入口为 [run_standard_cases.py](../tools/run_standard_cases.py)。基础自动测试仍由 CTest 管理。

这是一套项目内的标准验证算例初版，不是已获行业认证的基准库。当前算例覆盖不等于所有工况均可靠，尤其不能将 H8 的少量解析算例通过扩展为完整三维验证结论。

## 更新约定

1. 改动理论、材料或数值算法时，同步检查理论手册的公式与代码映射。
2. 改动输入、界面或输出时，同步更新用户手册和对应专门说明。
3. 每个算例保持输入、参考解、判据和报告可追溯；改变判据需要说明量纲与数值依据。
4. 增加功能时，先区分功能演示与精度验证，再选择适合的算例。
5. 对外发布前按发布源码重新编译、运行 CTest 和标准算例；将手册、输入和报告与软件版本一起归档。

README 是快速入口，三本手册是详细说明；[H8 工作台](../H8_WORKBENCH.md)、[自定义边界](../CUSTOM_BOUNDARIES.md)、[云图定义](../CONTOURS.md)作为用户手册的补充。
