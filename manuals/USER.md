# NonlinearFEM 用户手册

源码工作版初稿，2026-11-20。本手册适用于当前 Q4/H8 工作台。此前发布的 v0.1.0 软件包不包含后续加入的 H8、自定义边界和完整应力应变云图功能。

## 1 环境与首次运行

需要支持 C++17 的编译器、CMake 3.16 或更高版本。图形界面和 Python 验证脚本需要 Python 3 及 Tkinter，界面本身只使用 Python 标准库。Git 用于版本管理，不是求解必需依赖。

在项目根目录打开终端，执行：

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

本次环境检测到 Python 后有 33 项 CTest 检查；以本机 `ctest --test-dir build -N` 的实际输出为准。没有检测到 Python 时，部分 Python 检查不会注册。

然后双击项目根目录的 `LaunchGUI.cmd`。Q4 在主窗口中建模，右上角“三维 H8 工作台”打开三维窗口。

Visual Studio 等多配置构建需要 `cmake --build build --config Debug`，测试需加 `-C Debug`。对应可执行文件一般在 `build/Debug`。当前 H8 图形入口主要寻找项目根目录或 `build` 下的 `NonlinearFEM.exe`；多配置构建可先用明确路径执行命令行。标准算例脚本可通过 `--build-dir build/Debug` 指定目录。

## 2 单位与分析前准备

程序不自动转换单位。可采用 m、N、kg、s 的一致单位体系，此时杨氏模量为 Pa、密度为 kg/m³；应变无量纲。若采用其他长度单位，质量与密度也必须同时匹配，不能只把长度从 m 改成 mm。

开始分析前确定：采用二维平面应力还是三维实体、几何尺寸、Y 与 ν、Q4 厚度、支承位置、载荷含义，以及是静力加载还是随时间变化的问题。Q4 与 H8 的材料含义不同，不能只增加一个厚度方向的网格就默认得到完全相同模型。

图形界面当前生成矩形 Q4 或长方体 H8 的结构化网格，最多 600 节点。单元数可自行划分；当前没有任意几何造型或外部网格导入界面。

## 3 完成一个 Q4 静力算例

1. 启动主窗口，选择静力分析。
2. 选择悬臂、拉伸、固定端轴向、剪切或简支示例。
3. 用滑块或数值框设置长度、高度、网格数、厚度、杨氏模量、泊松比和总力。手动输入后按回车或移开焦点更新。
4. 先看原始网格及边界预览。蓝点表示节点具有位移约束，箭头表示节点力；方向和值可在边界编辑器中检查。
5. 点击“运行计算”。失败时先查看错误信息，不使用未收敛状态作为目标载荷结果。
6. 计算完成后，在结果菜单选择位移、第二 PK 应力或 GL 应变。默认变形倍率为 1。
7. 点击“查看完整云图与导出数据”打开独立查看器，或直接导出当前单元场量 CSV。

Q4 结果保存在 `results/时间戳/solution`。上一层保存输入模型；新生成的静力结果目录也包含模型快照。

## 4 完成一个 H8 静力算例

打开“三维 H8 工作台”，从悬臂体、轴向体或剪切体开始。设置 X/Y/Z 尺寸和三个方向的单元数；H8 的 Z 尺寸已经由实体几何表示，不再输入 Q4 的参考厚度参数。

点击“预览”核对网格，运行后在右侧查看结果。左键拖动旋转，滚轮缩放；“恢复视图”恢复视角和 1 倍位移显示。结果目录为 `results/h8_时间戳/solution`，上一层的 `solver.log` 保存运行信息。

H8 节点顺序见理论手册；手工编写模型时必须使用该顺序。图形生成器已按本项目顺序生成连接表。

## 5 自定义支承与载荷

Q4 点击“自定义 Q4 边界”，H8 点击“自定义约束与载荷”。编辑窗口分为“① 选择节点”和“② 边界设置”。

### 5.1 选择

单击节点切换其选中状态。可一键选择 X/Y/Z 最小或最大边界；Q4 没有 Z。边界按钮和编号选择可选择“替换选择”或“追加选择”。也可输入 `0,2,5-8`，节点编号从 0 开始。

H8 中拖动仍用于旋转；短距离单击用于选点。投影重叠时，转动视图后选择，或直接输入编号。橙色表示选中，蓝色表示有约束，红箭头表示节点力。

### 5.2 设置与删除

勾选需要处理的方向，输入位移并设置约束。未勾选方向不变。删除约束后该方向自由。静力可使用非零指定位移；动力只支持零位移约束。

总力输入值分别作为每个勾选方向的总力，在所选节点间均分。例如选 4 个节点、只勾选 Y、输入 -100，每个节点 fy=-25。再次设置覆盖对应自由度的旧值，不会自动累加。

这不是按面积或边长积分的均布牵引。原示例对端点和边点采用相应权重，自定义节点均分不保证同样权重；如需均布牵引，应分组指定合适的节点力。

表格显示所选节点的具体方向和值；清空选择后可看全部条目。“清除全部边界”允许从空白开始，不会自动补齐消除刚体运动所需的约束。

点击“应用到模型并关闭”后才生效；直接关闭会丢弃本次编辑。自定义启用后，总力滑块只作用于示例边界，不再修改自定义载荷。

### 5.3 修改网格

改变尺寸或网格数后，旧自定义节点边界会被拒绝。重新打开编辑器，以当前示例边界重新设置，或点击“恢复示例边界”。修改材料或 Q4 厚度不会改变节点编号，可保留边界。Q4 切换示例或恢复示例参数会恢复该示例边界。

## 6 动力分析

Q4 可选自由振动、渐增加载、突加载荷，H8 提供对应模式。

| 参数 | 含义 |
| --- | --- |
| density | 参考密度，必须为正，采用一致单位 |
| time_step | 时间步；0 表示依据初始刚度自动估计 |
| duration | 总时长，必须为正 |
| output_every | 每多少步保存一帧，正整数；初始和最终状态会保存 |
| initial_amplitude | 由运行器生成的初始位移扰动幅值；不是初始速度 |
| observation_node | Q4 可输入节点号或 auto；H8 当前界面自动选择示例加载面中部附近的节点 |

自由振动忽略输入节点力。渐增加载从零按 t/duration 比例增长，突加载荷从初始时刻使用完整节点力。当前 GUI 初始速度为零，无阻尼。

初始扰动采用轴向、弯曲、剪切或正弦弯曲形状，具体由示例模式决定；自定义边界会将固定分量置零。这不是模态分析，也不保证是新边界下的本征振型。

自动步长只依据初始状态。若运动明显发散，除了减小步长，还应核对约束、单位、载荷、模型适用性和能量变化。当前运行器最多允许一百万步和约两百万个保存节点状态，超限需减少时长、细化程度或增大保存间隔。

## 7 云图与导出

结果菜单包括位移大小、方向位移、第二 PK 应力、GL 正应变和工程剪应变，以及 von Mises（第二 PK）。Q4 只提供面内分量。

蓝到红表示数值从小到大。带符号分量按数值而非绝对值排序；负值绝对值更大不一定更红。颜色不能直接解释为安全程度。

自动当前帧使用当前数据范围；固定首次范围为每个分量锁定首次范围；手动范围在输入上下限并按回车后生效。超范围值用端部颜色显示。若初始结果全为零，应移到非零帧后重置固定范围，或使用手动范围。

极值标记对应单元平均结果。当前不平滑、不外推，极值不是高斯点峰值。H8 显示外表面，但内部单元也计入范围、极值与导出。

播放按保存帧顺序显示，不是按真实秒数播放。原始网格可用于核对放大变形；大倍率可能造成显示折叠，应回到 1 倍检查。

“导出应力应变”保存当前帧全部单元的数值。工程剪应变列名含 `GL_engineering_`，第二 PK 应力列名含 `PK2_`。原模型的 E、ν 是恢复场量的必要信息，移动结果时应保留模型快照。

## 8 文本模型输入

编号从 0 开始；载荷与约束方向 0/1/2 表示 X/Y/Z。`#` 后为注释。节点和单元记录按行给出，节点编号由出现顺序确定。

一个完整的单元 Q4 输入示例：

```text
NFEM 1
material 1000 0.3
thickness 0.2
nodes 4
0 0
1 0
1 1
0 1
elements 1
0 1 2 3
loads 2
1 0 0.05
2 0 0.05
constraints 3
0 0 0
3 0 0
0 1 0
newton 40 1e-9 1e-10
stepping 0.25 0.0001 0.25 0.5 1.5 8 100
end
```

`material` 后为杨氏模量和泊松比；`nodes`、`elements`、`loads`、`constraints` 后先给记录数。`newton` 的三个参数分别是最大迭代次数、残差容差、约束位移误差容差。`stepping` 依次为初始、最小、最大载荷增量、缩步系数、增长系数、最大重试次数、最大加载步数。

H8 使用 `NFEM3D 1` 作为文件头，每个节点三个坐标、每个单元八个编号，不包含 thickness。完整 H8 输入见 [H8_tension.nfem](../examples/standard/H8_tension.nfem)。

动力配置为：

```text
NFEM_DYNAMIC 1
density 1000
time_step 0
duration 1
output_every 10
initial_amplitude 0.001
observation_node 0
load free
initial_mode axial
```

`load` 可为 free / ramp / step；`initial_mode` 可为 bending / axial / shear / sine_bending。配置每项只出现一次，不使用模型格式中的自由注释语法。按实际节点数选择观察节点；0 可能恰好是固定节点，曲线为零并不表示模型没有运动。

## 9 命令行与结果文件

在项目根目录运行，输出目录必须尚不存在：

```powershell
build\NonlinearFEM.exe examples\standard\Q4_tension.nfem results\manual_q4_tension
build\NonlinearFEM.exe --h8 examples\standard\H8_tension.nfem results\manual_h8_tension
build\NonlinearFEM.exe --dynamic-h8 examples\h8_cantilever.nfem examples\h8_free.cfg results\manual_h8_dynamic
```

Q4 动力命令为 `NonlinearFEM.exe --dynamic model.nfem dynamic.cfg output_directory`。尽量使用相对路径与英文文件名；当前 Windows 命令行路径转换对非 ASCII 绝对路径存在限制。

| 输出 | 含义 |
| --- | --- |
| Q4 静力 nodes.csv | 坐标、最终节点位移、变形坐标、支座反力 |
| Q4 静力 history.csv | 静力加载记录；不是动力时间历史 |
| H8 静力 reactions.csv / load_history.csv | 支座反力 / 加载记录 |
| 动力与 H8 的 nodes.csv / elements.csv | 原网格和连接表 |
| frames.csv | 每个保存帧、每个节点的位移 |
| 动力 history.csv | 观察节点位移、速度、加速度，以及模型能量 |
| model.nfem / dynamic.cfg / analysis.txt | 输入快照和运行参数；按分析类型有所不同 |
| 查看器导出的场量 CSV | 当前帧的单元平均应力、应变和参考测度 |
| Q4 results.html | 保留的旧位移页面；完整应力应变使用本地查看器 |

H8 静力为复用查看器，会有只有一帧的 history.csv / frames.csv；其静力加载历史仍在 load_history.csv。未约束分量的反力通常记为 0，不是该自由度内力原始值。

## 10 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 找不到求解程序 | 核对编译是否成功及可执行文件位置；多配置构建检查 Debug/Release 目录 |
| 线性方程失败或计算不收敛 | 先检查刚体运动是否被约束、节点顺序、载荷大小和材料；静力可减少加载增量 |
| 提示旧边界不适用 | 网格已改变，重新编辑边界或恢复示例 |
| 动力拒绝非零约束 | 当前仅支持固定零位移，非零位移改用静力或后续扩展接口 |
| 输出目录已存在 | 换一个新目录，程序不会覆盖旧结果 |
| 云图看起来没有变形 | 核对载荷与约束、实际位移数值和倍率；较硬模型的实际位移可能很小 |
| 没有应力应变选项 | 检查结果旁的模型快照是否保留，不能只复制 CSV 位移文件 |
| 计算很慢 | 当前稠密线性代数适合小模型；先减少网格数，不能仅用单元数线性估计时间 |
| 受迫振动总能量改变 | 当前能量未扣除外力功，不能按无外力守恒问题解释 |

## 11 复现与归档

运行 [标准算例脚本](../tools/run_standard_cases.py)前先完成编译。建议归档本次源码版本或文件指纹、输入、计算日志、数值 CSV 和报告，再保存用于汇报的图片。图片应标明结果分量、应力测度、单位、时刻和显示倍率。
